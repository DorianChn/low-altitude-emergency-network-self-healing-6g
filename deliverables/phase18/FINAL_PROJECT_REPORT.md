# 最终项目报告

## 摘要

本项目提供一个可复现的灾后低空应急通信抽象仿真与软件演示平台，研究地面基站故障后，规则调度、滚动优化、事件驱动与多无人机策略对救援用户服务的影响。工作区保留各阶段原始种子结果、配置、统计摘要、可视化和数据完整性清单。Phase 18 对这些证据进行交叉核对，并在 React 研究页中集中呈现研究结果与限制。

## 科学问题与结论

项目的核心问题是：在健康回传、接入距离、容量、飞行和电量等抽象约束下，哪些调度逻辑能改善灾后救援用户通信，增益是否随场景变化。现有证据没有支持一个全场景最优策略。Phase 9 的事件驱动 E 在动态故障确认集低于 B′；Phase 11 的三机集中协同 G 在动态故障优于 F，但在高负载/回传受限场景劣于 F；Phase 14 更紧的链路预算可行性使所有主要策略对照的救援服务率下降。详细指标、置信区间和统计检验分别留在对应阶段原始 JSON 与报告中。

## 工程结果

- Python 仿真、事件生成、策略、容量分配和统计工具位于 `src/lowalt6g/`。
- FastAPI 暴露只读实验摘要与预生成回放，不控制真实网络。
- React `/research` 按实验阶段显示保存证据，支持回放/历史证据浏览。
- Phase 18 新增最终完整性 API 与审计工作台。
- 冻结历史哈希、清单和原始实验结构经本阶段审计核对；本地 RC 仍受混合工作区和未完成硬件验证限制。

## 适用范围

面向科研展示、算法机制比较和模型敏感性研究。不得作为运营网络规划、无人机飞行安全、频谱许可依据或真实 6G 性能承诺。
