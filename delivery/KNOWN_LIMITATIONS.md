# 已知限制与未验收事项

- 真实用户可用性测试未执行：用户明确豁免个人信息/报名流程，未伪造参与者或签核。视觉和操作经自动化浏览器验收，但不等同于真实用户反馈。
- Python 193 项、前端单测 21 项和浏览器 E2E 40 项均通过；Python 最终测试需在本机提升权限运行，因为受限沙盒阻断 Windows asyncio self-pipe 的 socket 操作。最终测试有 6 条 NumPy `corrcoef` 零方差运行警告；相关 Phase 15 校准源代码及证据文件按冻结要求保持原哈希。
- 真实射频设备、实际基站、目标设备校准、真实 HIL 和外场测量不在当前抽象仿真范围。软件验收不能替代人工签核或现场测量。
- 最终 30 分钟稳定性测试使用 Vite 开发服务器和本地 API；1,072 次场景/路由轮换、2,147 个 API 响应中没有页面错误、请求失败或非成功 API。浏览器 JS heap 每分钟69.7–162.7 MiB 波动并多次回落；这是单机 Chromium 开发服务样本，不构成跨机器或长时间生产内存 SLA。
- 冷加载每组仅 3 次，足以比较本机前后变化，不足以形成稳定的 p95 SLA。最终构建保留延迟加载的 ECharts chunk 533.66 kB（gzip 180.42 kB）提醒；Phase 6 首屏不加载它。
- 本机候选工程没有根级 LICENSE/COPYING/NOTICE；公开发布前仍需权利人确认图片/数据再分发权限。原项目未带入 14 个 Mendeley 原始工作簿/MAT 文件，其 DOI、许可和哈希见数据谱系；冻结清洗数据、配置、代码和结果已完整保留。
- 人工签核、真实用户报名及个人信息继续按用户指定范围豁免。
