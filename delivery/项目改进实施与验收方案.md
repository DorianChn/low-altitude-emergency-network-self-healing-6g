## 2. 项目目标和判定标准

总目标：使首次使用者能稳定打开项目，在五分钟内完成“选场景→看故障→切策略→看恢复→解释对比”，并能追溯关键结论。

| 编号 | 目标 | 验收条件 |
|---|---|---|
| G01 | 状态、数据与操作一致 | 六路由显示正确来源；四场景种子与当前artifact一致；快捷键不操作其他上下文；过期响应不覆盖新选择 |
| G02 | 启动可靠且可排错 | 指定演示环境正常启动/关闭10轮全部成功；路径含空格、缺依赖、占用端口和重复启动有明确结果；不误停无关进程 |
| G03 | 演示路径真实可执行 | 五分钟讲稿中的每个动作有真实入口；G3不再被写成/demo现有能力；材料明确单机回放与机队统计的范围 |
| G04 | 首次使用容易理解 | 至少3名未参与开发的真实参与者按任务卡完成核心流程，每人不超过5分钟；记录帮助、错误、耗时和未完成步骤 |
| G05 | 桌面与手机可操作 | 1920×1080、1366×768、390×844均可完成核心流程；补320/375/414px导航回归；仅数据表可局部横滚，主页面不横向溢出 |
| G06 | 性能可测且有收益 | 四场景首载各测至少3次，热切换各至少10次；报告可交互耗时、请求、解析及内存；优化前后条件一致且结果不变 |
| G07 | 长时间回放稳定 | 连续使用30分钟并循环场景/路由/策略切换，无未处理异常、遗留监听或服务进程；内存趋势有采样和解释 |
| G08 | 研究与版本可复核 | 每条保留的核心主张关联配置、数据、公式/脚本、结果和限制；源码快照、锁文件、日志与最终包相互对应 |
| G09 | 交付包可独立验收 | 新ZIP包含完整所需源码、运行资源、改动说明、测试证据及清单；独立解压副本能完成启动和关键测试，校验无差异 |

G06建议体验目标：在记录配置的指定演示电脑，冷页面进入到核心控件可用≤3秒、热场景切换到正确地图及控件可用≤1秒。它们是拟定目标，不是现有实测结论；开始性能工作前固定测量口径和环境。如果首测证明目标不适配，应先记录依据及目标调整，不在看到优化结果后改线以制造通过。

G04如没有真实参与者，提交任务卡和自测证据，状态为`NOT_TESTED`，不冒充三人评估。G07长测可后台执行并持续输出进度，不用单次长时间阻塞等待；机器条件不足时保留精确未测项。

4. 先做M01至M04，再做M05至M08；证据整理M10可交错推进。性能M09先量后改，避免没有收益的大规模重构。

## 4. 具体修改项目

### M01：当前页面的数据上下文与状态栏，P0

现状：`AppHeader`读取全局历史回放（种子2026），`Phase6DemoPage`独立读取7000/7020/7040/7060。顶部种子与正文冲突，全局接口错误可能误报独立正常页面不可用。

涉及位置：`frontend/src/components.tsx`、`data.tsx`、`replay-context.ts`、`Phase6DemoPage.tsx`、`App.tsx`；研究页通过其真实选中数据提供阶段/场景/策略元信息。

实施方法：

- 定义轻量当前页面状态模型：`ownerId、sourceId、sourceLabel、mode、scenarioId、seed、strategyId、loadStatus、error`。研究汇总没有单一种子时显示“多种子汇总”，禁止借用2026。
- 保留既有历史回放和演示回放各自的数据结构，通过适配器向统一状态栏提供元信息，不把不同实验合并为一个伪造数据集。
- 推荐在`BrowserRouter`内部放置当前页面状态Provider或路由布局；若使用`useLocation`，组件必须位于路由器内部。现ReplayProvider在BrowserRouter外，不能直接加入路由hook而不调整层级。
- 页面注册状态时附owner标识；异步完成或卸载清理仅能修改仍属于自己的状态，避免离开页面后的请求将新页面状态覆盖。
- 状态栏以当前数据请求为准显示加载/可用/错误，未加载时不残留旧种子；数据来源详情放在可展开说明中。
- 第一轮只解决所有权与正确性。按路由延迟加载无关历史接口属于后续效率优化，避免同时大改多个Provider。

验证：断言/demo四场景种子分别7000/7020/7040/7060；离开后历史回放显示2026；研究页不误用某一单种子。拦截历史接口返回500但保留/demo接口正常，演示状态不能误报失败；延迟旧响应后切路由，旧响应不得覆盖当前状态。

### M02：快捷键与回放生命周期，P0

现状：`data.tsx`全局注册键盘事件，/demo独立维护时间、播放状态。键盘可能操作旧回放，并存在跨页面后台播放风险。

实施方法：

- 提取`useReplayHotkeys(controller, enabled)`，控制器提供播放/暂停、步进、跳事件等动作；同一时刻只有当前路由的控制器激活。
- 移除旧的无条件全局监听，按路由适配现有状态，避免重写仿真结果或复制另一套回放数据。
- Space切换播放，左右方向键推进/回退一个真实采样步长；到边界保持边界，重新播放作为明确动作。步进时暂停，保证地图与时间轴同步。
- 输入框、文本域、下拉框、按钮、contenteditable、组合输入及Ctrl/Alt/Meta组合不拦截；检查嵌套元素/composedPath，避免编辑器内误触。忽略Space长按repeat造成反复切换。
- effect只安装一份监听并成对清理；路由卸载和文档隐藏时暂停非活动播放。重新显示时不未经用户操作自动恢复。
- React StrictMode及快速切页不能留下多份监听或计时器。时间与动作回调使用正确依赖或稳定引用，防止闭包持有旧时间。

验证：正文获得焦点时快捷键只改变当前回放；控件原生键盘行为不被破坏；跨路由后旧时间不再自动增长；挂载/卸载/再挂载一次按键只步进一次；首尾时刻无越界。

- 按实际界面重排五分钟流程，每步记录路径、场景、策略、事件/时刻、预期画面与讲解重点；避免写死可能变化的端口。
- 将“未测”“已测范围”和最新版本对应，保留历史审计不覆盖。检查方案/PPT/视频是否也含同样错误；若需要重导出，保存内容修改与渲染证据。

### M04：启动、依赖准备及诊断，P0

涉及：`scripts/start_demo.cmd`、`start_demo.ps1`，建议新增根目录`启动演示.cmd`、`准备环境.cmd`及相应PowerShell脚本；名字可调整，职责必须清楚。

实施方法：

- 根目录入口均以`%~dp0`/`$PSScriptRoot`定位项目，支持中文及含空格路径，不依赖调用者当前目录；提供简明“先准备、后启动、如何关闭”说明。
- 环境准备可以联网下载必要免费工具和锁定依赖，优先复用已安装或工作区工具；记录官方来源、版本和可取得校验值。首次无缓存不强制offline。
- 环境目录及缓存放项目可写专用位置；PATH优先仅当前进程生效。包内不能带引用旧绝对路径的venv或依赖旧复验目录才能启动的脚本。
- 启动前核实Python、uv、Node/npm兼容版本、依赖、回放文件与目录权限；错误提示含具体缺项、修复入口和日志路径。
- 对uv失败保存退出码、stderr、阶段和路径，分别排查锁、权限、进程残留、trampoline及环境变量。已有经锁文件准备且验证的venv可由其Python直接启动uvicorn，避免无条件依赖uv入口；不得静默改用未经核实的系统Python。
- 直接启动fallback应明确记录选用的解释器与环境核验依据；首次环境尚未准备时必须引导准备，不让错误依赖混入。
- 健康检查区分“端口可连接”与“当前项目服务就绪”；如复用已有服务，必须核对当前构建/数据版本标识，不能仅凭旧服务接口相似就复用。
- 动态端口分配与绑定之间可能竞争，记录并有界重试；重复启动明确“复用已确认的同版本会话”或“新建独立会话”，不能误控其他候选版本。
- 会话记录包含runId、PID、启动时间、监听端口、工具路径、日志及健康结果；关闭仅清理本次拥有的进程，验证退出与端口释放。后台服务隐藏启动。
- 不修改防火墙、安全策略或系统级执行策略；不靠全局删除临时目录解决锁问题。

验证：正常10轮；缺uv/npm/依赖/回放；只读目录；中文空格路径；预占端口；故障子进程；Ctrl+C/自动超时；重复启动；启动失败后再恢复。只读/权限等异常应给出清晰失败而非要求它们强行成功。保留无关进程作为哨兵，确认未被清理。

### M05：事件过滤、中文解释与关键跳转，P1

涉及：`Phase6DemoPage.tsx`、`presentation.ts`及事件相关类型/测试。

实施方法：

- 建立分类：初始故障、站点故障/恢复、回传中断/恢复、容量/业务变化、网络恢复、普通调度。界面默认突出关键环境和恢复事件；普通调度可展开或切换“全部事件”。
- 展示过滤只作用于派生数组，原始event_log和事件总数不改。提供“当前筛选数量/全部数量”及无匹配提示。
- “上/下一个关键事件”严格按关键集合、唯一时间戳导航；同刻多个事件全部保留。没有后续事件时禁用并说明，不悄悄跳到0。
- 复用已有decisionLabel，补齐原因与对象的中文映射；未知编码显示“未识别记录”及可展开原始值，不把未知原因猜成故障。
- 保留事件详情、原始字段及数据定位。相邻帧差值仍注明仅为共同观测，不自动宣称单个事件的因果效果。
- 不把真实失败、负面结果或未恢复情况作为“噪声”隐藏。

验证：原始事件hash不变；过滤与清空恢复全部记录；关键跳转避开普通调度；同刻事件和首尾边界正确；未知类型可读且可追溯。

### M07：移动端、可访问性及首次使用路径，P1

实施方法：

- 首页提供“开始五分钟演示”和“查看研究证据”的主任务入口，保留现有专业导航。演示页给出三步可跳过指引，不能用强制弹窗阻挡已熟悉用户。
- 手机使用sticky回放工具条，设置safe-area与滚动留白，避免遮住焦点和内容；桌面提供回放/结果/证据锚点。
- 次要调度和研究说明面板折叠但可键盘操作；关键异常和当前状态不折叠隐藏。
- 结果表固定策略列、增加横滑提示；可提供摘要卡与完整表切换，但完整指标可访问，不能靠删列解决适配。

- 保持可见焦点、语义标题、控件标签、非颜色唯一编码，尊重reduced-motion。改造不能破坏原有AbortController、错误重试、定时器清理和懒加载。

验证：各视口任务流程、键盘Tab顺序、焦点不被sticky遮挡、表格局部横滚、200%缩放及减少动画模式；截图在相同滚动位置比对。页面更短不是独立成功标准，以任务完成和可读性判断。

- ECharts包体积提示结合实际首屏和分包分析处理；研究页已有lazy加载，不重复“新增”已有能力，不只为消除提示盲目拆分。

### M09：端到端性能测量与有界优化，P2

先测量：导航开始到核心交互可用、场景变更到正确地图/控件可用、API读取/解析/序列化/传输、浏览器解析/渲染、进程RSS及浏览器可获取内存分别记录。浏览器内存API不可用时写明，不用错误读数充当峰值。

仅在证据显示有收益时实施：

1. 后端场景缓存：容量上限/字节上限明确，key含场景及文件版本/摘要，文件变化能失效；共享缓存对象只读，必要时返回不污染源对象的数据。避免用微小收益换取大内存常驻。
2. 前端请求去重和有限缓存：复用既有取消能力，限定缓存条数；保留来源校验，旧响应不得覆盖当前选择。

4. ECharts按实际图表引入或拆包：对照构建产物及首屏/研究页加载，不只是把同样字节换一个chunk名称。
5. 大对象处理：定位重复JSON解析、深拷贝、每帧不变量计算或排序；避免未经profile就重写算法。算法优化应另列计算时间和结果一致性，不改变约束、搜索质量或随机种子口径。

### 8.2 清单与校验的自引用规则

- `FILE_MANIFEST.json`记录载荷相对路径、大小、SHA-256和排除规则，不列自身、SHA256SUMS及ZIP，避免循环hash。
- `SHA256SUMS.txt`记录载荷及FILE_MANIFEST的hash，不包含自身。
- 最终ZIP整体hash放ZIP外的同名`.sha256.txt`，最终校验结果放外部`delivery-validation.json`。
- 包内记录releaseId和测试源码/运行载荷manifest，不能把最终ZIP自身hash写回包内造成循环。

### 8.3 独立解压验收

1. 从发布目录生成候选ZIP并完整解压，检查安全路径、重复/大小写冲突、CRC、载荷数量、大小和hash。
2. 在独立路径、新shell中按包内说明准备环境，不能偷偷复用指向原工程的venv或绝对路径；缓存复用如实登记。
3. 执行根启动入口、API/页面健康、上下文及快捷键关键E2E、主要场景和正常关闭。完整回归已在最终源码上执行时，可用运行载荷hash一致性复用该结果，独立解压启动不能省略。
4. 将副本测试记录写入发布目录文档后重打最终ZIP，比较源代码、配置、数据和运行资源与已测候选的运行载荷hash；仅文档/审计记录变化须明确列出。
5. 对最终ZIP再完成CRC、清单、大小/hash、安全路径及完整解压核验。若运行载荷改变，则重跑受影响测试及解压启动，不能用旧结果替代。
6. 创建外部ZIP校验文件和校验报告，最终回复给出ZIP、改动说明、验收报告位置以及真实状态。

不得仅将旧ZIP改名作为新版本；不得声称与已测代码等价而没有逐文件依据。下载工具目录不需要完整带入ZIP，最终说明必须足以从缺依赖环境重新准备。

## 9. 完成门槛与无法执行项的处理

最终通过需：P0问题关闭；必需功能及回归无未解释失败；受保护实验数据不被改写；必要说明、证据和完整ZIP齐全；独立解压核验通过。

P1按本方案实施并验证。P2先测后决策，证据支持不改也可作为完成，但必须说明测量和理由。外部历史证据、真实参与者、原生Office或物理断网条件若无法取得，继续完成其他任务，在状态表中保留未测及影响，不能勾成完成。

如果所有任务不能真实完成，不声称“全部完成”。仍交付可审阅的工程ZIP，文件名及报告明确标为候选/部分完成，逐项列出未完成、原因、影响和复验步骤；核心功能FAIL不得标正式通过。

所有任务实际完成后，最终ZIP必须内附全部改动说明、实际测试报告、环境复现方法和剩余限制，不能只给出代码片段或工作区路径。
