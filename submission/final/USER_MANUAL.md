# 现场用户手册

## 准备
Windows 11 电脑，建议 1920×1080；准备 Python、uv、Node.js 和锁定依赖。现场前需完成断网和第二设备实测（当前未完成）。把解压目录放在可写位置。确认 results/phase6_demo_*.json 存在。

## 启动
在项目根目录双击 scripts/start_demo.cmd，使用脚本输出的动态 UI_URL/API_URL。脚本等待 API 就绪并输出入口。PowerShell 入口为 scripts/start_demo.ps1。不要将 5173/8123 当固定端口，不要终止未知进程，不需要管理员权限。

## 演示
1. / 首页。
2. /command 指挥中心。
3. /demo：四种场景，切策略、暂停/继续、拖时间轴、跳事件。
4. /decision 决策与不可行原因。
5. /lab 算法对照。
6. /research 链路模型/数据来源。
7. 用脚本正常关闭。

## 指标解释
服务率是仿真时隙统计；恢复按全部救援用户完整连接判定；时延是成功连接样本条件统计；Wh 为模型能耗；算法耗时为本机墙钟时间。都不是现场测量。

## 备用
当前没有实际断网测试。准备方案/PPT PDF、对照图和截图；API不可用时只做静态讲解并说明交互故障。不要把截图称为实时数据。

## 现场禁止
不接射频设备、不发送信号、不控制未授权硬件、不修改防火墙/安全策略、不运行400次确认实验、不用随机数据填充页面。
