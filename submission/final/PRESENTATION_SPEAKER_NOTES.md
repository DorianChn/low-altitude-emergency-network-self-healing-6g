# 答辩 PPT 逐页讲解备注

1. 封面：项目定位为灾后救援通信研究原型。
2. 场景：站点故障和回传中断会同时影响端到端服务。
3. 问题：回答可行性、连续性和算法代价三个问题。
4. 架构：从场景、状态、决策、安全执行到 API 和回放。
5. 模型：距离、容量、时延、飞行、电量是配置化抽象。
6. 策略：A–J 为规则/优化方法，不是训练型机器学习。
7. 多机结果：严重场景增益明显，动态/高负载不统一。
8. 动态故障：E 的负结果说明事件触发本身不足。
9. 对照算法：按场景和机队规模读数，不称全局最优。
10. 链路模型：链路预算会拒绝几何上可达但预算不满足的路径。
11. 数据：570 条公开留出，只支持公开条件下的误差比较。
12. 数字孪生：JSON离散帧，有暂停/跳转，不是live。
13. 复现：种子、轨迹哈希、失败分母、原始JSON。
14. 安全：21/21 合成故障注入通过，不是物理HIL。
15. 局限：设备测量、许可证和现场验收待处理。
16. 总结：强调模型内证据和明确边界。
