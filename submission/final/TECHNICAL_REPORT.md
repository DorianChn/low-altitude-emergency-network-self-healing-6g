# 技术报告：低空应急网络的可复现自愈仿真

## 1. 问题定义
研究灾害导致基站或回传失效后，低空无人机中继怎样在共同容量、服务优先级、飞行和电量限制下，帮助救援用户恢复端到端服务。必要条件是用户接入链路、无人机服务容量、可用回传路径及基站容量均可行；没有健康回传时必须判为不可行。

## 2. 架构与数据流
配置产生带种子的基站、用户、业务负载和事件；网络引擎计算链路与资源；策略读取当前状态并提出目标动作；仿真执行层统一检查飞行、容量、回传和储备约束；指标与事件写入 JSON；API 提供只读查询和离线回放；前端消费 API 展示数据。
关键位置：configs/、src/lowalt6g/dynamic_world.py、engine.py、dynamic_simulation.py、multi_uav_simulation.py、phase10_experiments.py、phase11_experiments.py、api.py、frontend/src/。

## 3. 网络抽象
网络由离散空间的地面基站、用户、回传链路与无人机中继构成。场景施加持续故障、运行中故障、用户移动、业务突增及回传容量限制。距离/链路预算、容量和时延均由配置驱动；随机种子用于重建同一仿真世界。仿真没有建筑级传播、频率选择性衰落、共享频谱干扰和真实协议栈。

## 4. 无人机与资源安全
单机/机队具有位置、任务、链路、电量和服务资源状态。公共执行层逐步执行可行动作，限制速度、边界、单机容量、电池储备和返航可行性；多机共享基站容量不按无人机数复制，用户只计一次服务。能耗由移动、悬停和中继项按仿真时间累计，参数是研究假设，未经过项目设备校准。

## 5. 策略族
A 为无无人机恢复对照；B/B′ 为静态网格目标基线（B′采用统一完整 sortie 预算）；C 为滚动时域加权优化；D 为救援优先词典序优化；E 为状态变化触发的事件驱动重规划；F 为逐机独立贪心；G 为集中式有限候选联合搜索；H 为边际救援覆盖贪心；I 为用户—中继资源分配匹配（不解决完整轨迹联合规划）；J 为受限计算预算的联合候选搜索。C–J 均为规则或确定性优化，不是训练模型。

## 6. 实验设计与统计
采用开发与留出种子分区、同一灾害种子策略配对、保存逐次 JSON 和配置/轨迹哈希。四类场景包括严重持续故障、动态故障、高移动救援、高负载及回传受限。指标包括救援/普通用户服务率、首次完整恢复、连续 30 秒恢复、恢复时间、条件时延和 P95、无人机能耗、算法耗时和资源使用。
未恢复运行保留在成功率分母；恢复时间同时报告成功数/总数及删失口径。时延仅对成功连接的用户时隙计算，不同策略成功样本集合不同，不能解释成同一用户上的因果效应。

## 7. 关键证据
- Phase 10：4 场景、80 个确认种子、400 次运行。严重故障中 B′ 服务率 58.66%，G2 66.58%，G3 66.89%；动态故障中 B′ 21.36%，G3 22.18%；高负载中 F3 49.99%，G3 47.40%。多机收益依场景而变。
- Phase 11：4 场景、80 个确认种子、880 次运行。动态场景 B′ 18.14%、G3 19.22%，但区间和完整/持续恢复须一并解释；没有跨场景统一赢家。
- Phase 9：动态故障 E 对 B′ 服务率差 −7.05 pp，持续恢复差 −60 pp，算法计算多 553 ms/运行；零检测延迟没有抵消动作质量不足。
- Phase 14：链路预算模型使动态故障 B′ 服务率由 19.70% 降到 7.50%，显示距离阈值会高估可行链路。
- Phase 15：570 个公开 over-water 留出样本上，候选 MAE 1.8195 dB，Phase 14 基线 7.1864 dB；仅适用于该公开数据条件。

## 8. 前端与接口
FastAPI 暴露只读健康、历史实验、研究数据、回放和图表路由；React 六个路由为 /、/command、/decision、/lab、/demo、/research。播放为预计算离散帧，暂停/继续和跳帧不生成新仿真状态。API、场景、回放和指标一致性通过 pytest/Playwright 断言。

## 9. 安全边界
软件故障注入 21/21 通过，软件执行器使用隔离内存夹具，设备输出关闭；没有真实无线发射、飞行或 HIL。uv audit 发现 pytest 8.4.2 开发依赖公告（修复 9.0.3；影响描述针对 Unix 临时目录语义）；npm audit 为 0。根目录没有项目许可证。
