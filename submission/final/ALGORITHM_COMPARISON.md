# 算法对比与适用范围

| 策略 | 决策机制 | 证据边界 |
|---|---|---|
| A | 无无人机恢复动作 | 仍可能依赖预设地面维修；不是“永不恢复”基线。 |
| B | 一次性静态网格选址 | 低计算成本；动态故障中常优于滚动优化，但状态改变后不换点。 |
| B′ | B 目标 + 统一 sortie 能耗/返航约束 | 多机规模比较强基线；和 B 语义不同，须单独标识。 |
| C | 加权和滚动时域搜索 | 计算更贵；动态故障服务率/持续恢复曾低于 B。 |
| D | 救援优先词典序优化 | 目标明确不等于一定更快或更可靠。 |
| E | 关键状态事件触发重规划 | 动态故障服务率低于 B′，持续恢复更差；零检测延迟不是恢复收益。 |
| F | 逐机独立贪心 | 多机基线；执行引擎统一共享容量。 |
| G | 集中式有限候选联合搜索 | 部分场景改善，集中协调成本较高；无全场景优势。 |
| H | 边际救援覆盖顺序贪心 | 低成本协同基线；动态和部分场景弱于 F/G。 |
| I | 用户—中继资源匹配 | 解决资源分配子问题，不是完整轨迹优化。 |
| J | 受限预算联合候选搜索 | 与 G 对比搜索预算和候选空间；须按实际预算解释。 |

## 实用选择
严重持续故障：多机在模型内增加服务，但耗能增加。
高移动/高负载：Phase 10–11 的 F/G 部分结果提高，仍依赖共享回传容量和链路模型。
动态故障：静态基线在多个批次稳定；E 尚未显示服务增益。
不存在当前证据支持的全场景统一最优算法。
