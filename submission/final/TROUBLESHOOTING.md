# 故障排查

## 浏览器拒绝连接
确认 start_demo.ps1 打印的 UI_URL/API_URL。端口可能动态分配，127.0.0.1:5173/8123 不是固定入口。查看脚本日志并正常重启本次服务；不要杀未知进程。

## 缺依赖
现场需预装 Python、uv、Node.js 与锁定依赖。启动脚本不会静默修改 PATH、安全策略或安装服务。

## 页面可开但场景失败
访问当次 API health，检查预计算 Phase6 JSON。缺失数据应显示 unavailable，不会用随机值填充。

## 端口和 E2E
本机 5173/8123 有既有服务，本轮未停止。浏览器测试使用独立端口并管理自有进程。

## 断网备用
本轮没有物理断网测试。可展示方案/PPT PDF、对照图和审计截图，但不能声称 API 交互已验证离线。
