# 6G / RESCUE — 比赛交付目录

本目录是 Phase 1–18 的本地审计与竞赛材料集合。候选包仅供团队审阅，不是正式发布；没有报名或提交到赛事平台。

## 建议阅读顺序

- `PROJECT_OVERVIEW.md`：项目概览
- `TECHNICAL_REPORT.md`：系统、方法与证据边界
- `EXPERIMENT_EVIDENCE.md` 与 `ALGORITHM_COMPARISON.md`：实验数据与算法口径
- `TEST_REPORT.md`、`SECURITY_AUDIT.md`：测试和安全/许可审计
- `FINAL_DELIVERY_AUDIT.md`：最终审计结论
- `SUBMISSION_CHECKLIST.md`、`PENDING_MANUAL_CONFIRMATION.md`：提交前人工确认
- `USER_MANUAL.md`：现场运行手册
- `package/6g-rescue-phase18-review-candidate-20261021.zip`：独立审阅候选包
- 候选包旁置的 `audit/package_validation.json`、`audit/final_acceptance.json`：候选包与阶段验收状态。它们不嵌入 ZIP，以免验证文件记录自身所在压缩包的校验状态
- `audit/PACKAGE_VALIDATION_LOG.md`：候选包隔离验证与修复记录
