# GitHub publication layout

This repository is a lightweight, browseable source view. Files at or above 10 MiB are kept out of Git history for clone and push efficiency; the complete Release ZIP contains every raw result and deliverable. The project data limits and hashes are listed in [GITHUB_LARGE_ARTIFACTS.md](GITHUB_LARGE_ARTIFACTS.md). The full-package checksums in [delivery/](../../delivery/) are intended for the Release ZIP. [GITHUB_SOURCE_MANIFEST.json](../../GITHUB_SOURCE_MANIFEST.json) and [GITHUB_SOURCE_SHA256SUMS.txt](../../GITHUB_SOURCE_SHA256SUMS.txt) are the 2026-10-22 source-view snapshot (637 paths and hashes). They still list phase reports at the repository root and were not regenerated when those reports moved to `docs/phases/`.

The project has no LICENSE file because no code license was selected. Third-party asset attributions are in `assets/credits.json`.

This is an abstract research simulator and offline replay prototype, not a real 6G network or field-device test.
