# Phase 18 已知问题与限制

## 历史证据/版本

1. 找不到 Phase 7 的可复核材料，不能还原其实现或结果。
2. Phase 5 两个源码哈希与当前版本不同；没有逐阶段提交，无法精确归属代码演进；冻结数据文件哈希仍通过。
3. 当前 Git 工作区有跨阶段已有修改和大量未跟踪文件。安全边界不允许批量暂存或提交这些混合内容，故本地 RC 尚未形成干净 Git 快照。

## 科研边界

1. 传播、建筑遮挡、相关阴影、噪声、无线干扰/SINR、协议栈与真实排队过程仍为简化或未建模。
2. 移动、悬停和中继功耗参数没有项目无人机实测校准，结论仅是模型敏感性结论。
3. Phase 15 使用公开 3.6 GHz A2G 数据，验收因缺测量不确定度无法判定；它不能代替项目设备校准或城市灾害场景实测。
4. Phase 16 没有项目设备测量或外场采集；现场测量准备状态未就绪。
5. Phase 17 的软件闭环由合成测试植物驱动，未执行物理 HIL；离线数字孪生使用真实保存帧，但不连接物理网络。
6. B、B′、C、D、E、F、G、H、I、J 是规则或确定性优化策略，不是训练完成的机器学习系统。不同研究阶段使用的模型与协议不可随意合并统计。

- 第二台设备和正式比赛场地离线启动未实际验证。
- 浏览器在当前构建环境通过后，仍应在目标显示器和现场电脑上复核字体、浏览器版本及端口策略。
