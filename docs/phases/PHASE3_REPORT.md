# 第三阶段交付报告：沉浸式数字孪生前端

更新日期：2026-10-18  
项目：面向6G的低空应急网络智能自愈平台  
实现范围：React 前端与只读 FastAPI 仿真数据接口

## 页面完成情况

| 页面 | 路由 | 实现内容 |
|---|---|---|
| 沉浸式首页 | `/` | 巨型「6G / RESCUE」标题、城市夜景氛围图、仿真 SVG 网络场景、当前网络指标、时间轴和策略对照入口。城市影像只作背景，不伪装成仿真地图。 |
| 数字孪生指挥中心 | `/command` | 按选定策略和回放时刻展示基站、故障、用户、链路及无人机；含事件时间线、用户状态、连接指标和回放控制。 |
| AI 自愈决策中心 | `/decision` | 展示仿真记录中的规划目标、决策原因、不可行原因、状态诊断、回传状态、电量及规划约束；页面不向无人机或基站发送控制。 |
| 算法性能实验室 | `/lab` | 提供 Phase 2 A/B/C 历史基线和 Phase 5 多灾害留出验证，包含场景选择、图表、置信区间、恢复/未恢复统计和逐策略结果表。 |

四页共享同一回放状态，按真实保存的仿真帧驱动节点位置、连接状态、无人机位置、事件和指标。实验室按场景切换实际验证数据，不以示意动画或写死数字替代结果。

## 技术与视觉实现

- React 19、TypeScript、Vite 8、Tailwind CSS 4；界面采用项目级设计令牌与 CSS 布局，Tailwind 用于构建集成。
- GSAP 用于克制的页面入场和交互动效；组件以 GSAP context 管理清理，并为 `prefers-reduced-motion` 提供无入场动画路径。后台标签页不启动入场动画，避免浏览器节流后页面停留在透明状态。
- ECharts 6 以动态导入方式只在实验室需要时加载，图表仅注册柱状图、折线图、网格、图例、提示框与 Canvas 渲染器。
- 城市网络图使用 SVG 绘制精确节点和链路，不启用持续渲染的 WebGL 场景；首页照片与数据地图明确分层。
- 深黑、酒红和橙红延续参赛视觉方向；操作页保留较高对比度、单位、样本范围及仿真来源说明。

## 前后端集成

前端通过 Vite `/api` 代理读取本地 FastAPI。现有只读契约为：

- `GET /api/health`
- `GET /api/replay/{seed}`
- `GET /api/experiments/phase2`
- `GET /api/experiments/phase5`
- `GET /api/experiments/phase5/{scenario_id}`

数据来自 `results/phase3_replay_seed_2026.json`、Phase 2 历史实验及 Phase 5 多场景验证产物。`/api/health` 明确返回预计算离线回放状态。系统是面向 6G 研究的抽象仿真，不是实际无线网络、基站或无人机设备测试，也不提供实时设备控制。

## 本轮验证结果

- `npm.cmd run lint`：通过。
- `npm.cmd run build`：通过，TypeScript 检查通过，Vite 构建完成。
- Taste 多尺寸浏览器检查：实验室在 1280、768、390 CSS 像素视口完成检查；此前检查包含 1920 像素宽桌面视口。页面无视口级横向溢出，手机和平板上的策略结果表按设计保留横向滚动。
- Taste Inspector 本轮返回 6 FAIL / 6 WARN。海报式首屏、宣传照片/视频和持续动效规则不适用于科研操作台；黑红氛围光、数据分隔线和 14px 技术说明符合当前视觉与信息密度取舍。它仍将 10 列实验表计作 side-scroll 警告；页面现已提供可见提示和键盘可聚焦区域，此项保留为有意的表格行为，不伪报为零警告。
- 浏览器交互核验：仿真 API 数据成功加载；Phase 2 / Phase 5 标签切换有效；从「严重持续故障」切换到「动态故障」后，标题和所选场景同步更新；浏览器控制台无错误。
- 本轮修复了结果表的移动端可发现性：实际出现溢出时显示「横向滚动查看全部指标」提示；表格容器可通过键盘聚焦并带有中文区域名称；列标题增加 `scope="col"`。在当前浏览器 1274px 视口下，Phase 5 表容器宽 1162px、表格宽 1450px，横向溢出和提示均符合设计预期。
- Impeccable 机械检测：`frontend/src/pages.tsx` 与 `frontend/src/index.css` 返回空 findings（`[]`）。
- 生产构建仍报告 ECharts 懒加载 chunk 为 533.66 kB（gzip 180.42 kB），超过 Vite 默认 500 kB 提示线；它不属于首页初始入口包，且图表已做按需注册。本轮不为消除提示拆分图表实现。
- 本轮只改前端，没有重跑 Python pytest。浏览器窗口处于隐藏状态，浏览器工具拒绝发送实际键盘输入；本轮确认了区域的焦点语义和标签，但未完成物理键盘/触控设备手势测试。

## 当前限制与后续事项

1. 回放和实验页面读取的是已经生成的结果文件；网络事件不会在页面中实时生成，AI 决策中心展示记录而非在线重新规划。
2. 6G 无线传播、干扰、协议栈、真实基站和飞行器动力学均由抽象模型代表，页面不应被描述为现场网络测试。
3. ECharts chunk 仍有体积提示；实验室以外的页面不会因该模块而同步加载这段代码。
4. 已完成多尺寸浏览器渲染检查；真实触屏惯性滚动、屏幕阅读器和实际 1920×1080 显示器仍需现场设备验收。
5. 本轮没有重跑 Python 测试，也没有进行真实硬件、网络射频或 6G 性能测试。

## 启动

在项目根目录启动 API：

```bash
uv run uvicorn lowalt6g.api:app --host 127.0.0.1 --port 8123
```

在 `frontend/` 目录安装依赖后运行：

```bash
npm run dev -- --host 127.0.0.1
npm run lint
npm run build
```
